# FetalNeuro

Учебное PWA-приложение по нейросонографии плода с 11 недель: срезы со схемами и легендой, норма, измерения, типичные ошибки, ранние находки, тест.

Автор: Жумагулов Н.М., врач ультразвуковой диагностики.

## Структура

| Файл | Что внутри |
|---|---|
| `data/meta.js` | Название, версия, периоды (`PERIODS`: 11–14 нед, базовое II–III триместр, прицельная нейросонография) и план ненаписанных разделов (`PLAN`) |
| `data/views.js` | Срезы: техника, норма, измерения, ошибки, находки, структуры на схеме, источники |
| `data/quiz.js` | Вопросы теста (`a` — номер верного варианта с 0, `link` — id среза) |
| `data/references.js` | Реестр источников, сверенных с PubMed (PMID и DOI) |
| `schemes.js` | SVG-схемы срезов (номера на структурах, расшифровка — в легенде карточки) |
| `validate.js` | Валидатор контента (браузер + Node) |
| `search.js` | Поиск: ё/е, регистр, синонимы, аббревиатуры, все поля |
| `progress.js` | Экспорт/импорт прогресса в JSON |
| `app.js`, `style.css`, `index.html` | Интерфейс |
| `sw.js`, `manifest.json`, `install.js` | Офлайн-режим и установка |
| `tests/` | Автоматические тесты |

## Медицинский контент

- Все срезы, схемы и вопросы — `status: "draft"` до экспертной проверки автором. `approved` валидатор принимает только с `reviewedBy` и `reviewedAt` (ГГГГ-ММ-ДД).
- `verified: true` у источника означает: утверждения указанного раздела (обычно цифры) сверены с резюме статьи в PubMed. `section: "card"`, `verified: false` — документ по теме, соответствие конкретным утверждениям не сверено.
- Руководства ISUOG по ЦНС (часть 1 и 2) уже в реестре — для разделов II–III триместра.

## Добавить срез

1. Запись в `data/views.js` (поле `period` — id из `PERIODS`; `structures` — номера 1, 2, 3… подряд).
2. Функция схемы в `schemes.js` с теми же номерами (`num(n, x, y)`), регистрация в `FN.SCHEMES`.
3. Убрать соответствующий пункт из `PLAN`.
4. Новые файлы — в `FILES` в `sw.js`, поднять `VERSION`.
5. `npm test`.
